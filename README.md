# Space Shooter Pygame

เกมยิงยานอวกาศพัฒนาด้วย Python และ Pygame มีระบบหลายด่าน (Stages), หน้าจอเมนูหลัก, และระบบปรับความยาก

## 🎮 ฟีเจอร์ของเกม
- **Start Screen:** หน้าจอเมนูหลักก่อนเริ่มเกม พร้อมคำแนะนำการควบคุม
- **Multi-Stage Progression:** แบ่งออกเป็น 3 ด่าน (Stage 1, 2, 3) พร้อมหน้าจอผ่านด่าน (Stage Cleared) และหน้าจอชนะเกม (Victory)
- **Auto-Fire:** สามารถกดปุ่ม `SPACE` ค้างไว้เพื่อยิงกระสุนต่อเนื่องอัตโนมัติ
- **Balanced Difficulty:** เลือดเริ่มต้น 5 HP และปรับความสมดุลความเร็ว/อัตราการเกิดศัตรูให้เล่นสนุกและง่ายขึ้น
- **Game Over & Restart:** เมื่อ HP หมดสามารถกดปุ่ม `R` เพื่อเริ่มเล่นใหม่ได้ทันที

## 🕹️ การควบคุม (Controls)
- **เคลื่อนที่:** ลูกศรซ้าย/ขวา (`←`, `→`) หรือปุ่ม `A`, `D`
- **ยิงกระสุน:** กดปุ่ม `SPACE` ค้างไว้ (ยิงต่อเนื่องอัตโนมัติ)
- **เริ่มเกม / ไปด่านถัดไป:** กดปุ่ม `SPACE` หรือ `ENTER`
- **รีสตาร์ทเกม (เมื่อ Game Over / ชนะ):** กดปุ่ม `R`

## 🛠️ วิธีการติดตั้งและรันเกม
1. ติดตั้ง Python (แนะนำ Python 3.12 ขึ้นไป)
2. ติดตั้งไลบรารี Pygame:
   ```bash
   pip install pygame
   ```
3. รันเกม:
   ```bash
   python main.py
   ```
